# Агрегатор вакансий

Персональный бот для одного пользователя. Раз в сутки собирает вакансии из нескольких
источников, отбирает подходящие по региону и направлению и присылает владельцу одно
сообщение в Telegram со списком и ссылками.

Направление отбора — оценка и развитие персонала (T&D / L&D, ассессмент, HRBP,
корпоративный университет, управление талантами).

География — Нижний Новгород и Нижегородская область либо удалённая работа.

## Как устроено

```
sources/   адаптеры источников, каждый возвращает список вакансий
core/      модели, фильтры, дедупликация, сборка дайджеста, отправка
main.py    оркестрация
```

Конвейер: собрать → нормализовать → отфильтровать → отсеять уже виденные →
собрать дайджест → отправить → записать новые id в хранилище.

Показанные вакансии хранятся в SQLite (`seen.db`), поэтому одна и та же вакансия
не приходит дважды.

## Запуск

Секреты берутся из переменных окружения, список — в [.env.example](.env.example).
Локально можно положить их в файл `.env` (он в `.gitignore`).

```bash
python main.py
```

Запуск по расписанию — GitHub Actions, ежедневно в 09:00 по Москве.
